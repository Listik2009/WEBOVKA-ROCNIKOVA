Phu Quoc Travel

O projektu

Tento web byl vytvořen jako návrh cestovní agentury nabízející dovolené na ostrově Phu Quoc ve Vietnamu. Uživatel zde najde informace o ubytování, výletech, wellness službách a možnostech rezervace pobytu.

Jak web funguje

Po otevření hlavní stránky si může návštěvník prohlédnout nabídku pobytů a služeb. Pomocí navigačního menu se dostane na další podstránky, kde najde podrobnější informace. Součástí webu je také kontaktní a rezervační formulář.

Mapa stránek

- Home

Popis stránek

-Home – představení destinace a hlavních služeb.  
-O nás – informace o cestovní agentuře.  
-Resorty – nabídka ubytování.  
-Výlety – přehled organizovaných výletů.  
-Blog – články a tipy pro cestovatele.  
-Kontakt– kontaktní údaje a formulář.  
-Rezervace – formulář pro rezervaci pobytu.  
-Relax & Wellness – nabídka wellness služeb.  
-Ceník – přehled cen pobytů.  
-Půjčovna – nabídka pronájmu dopravních prostředků.
